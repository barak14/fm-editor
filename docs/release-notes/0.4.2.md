# FM Editor 0.4.2 — preview notes

Unsigned experimental preview for Windows x64 and Linux x64 (Proton). Back up
saves and use offline single-player saves only. FM27 Game Pass remains
unverified and Epic installs remain unsupported (see the
[0.4.1 notes](0.4.1.md#compatibility-limits)).

## Changes since 0.4.1

FM24 Steam (24.4.2) moves much closer to FM27. Every new mapping was checked
against FM24's own screens in a test save, and every new edit was confirmed in
game and undone. FM26 and FM27 behaviour is unchanged.

- **Player injuries, bans and holidays** on FM24, with **Heal** and
  **Lift ban**. Players without any medical record show "None".
- **Other nationalities, favoured clubs and contract bonuses/clauses** on
  FM24; bonus amounts are editable.
- **Contract start, transfer/loan listing and asking price** on FM24's
  Contract tab. Transfer and loan listing and the asking price are editable.
- **Game date** on FM24: exact ages, and transfer listing records the date.
- **Transfer value** shown read-only on FM24 (FM recalculates it every game
  day, so edits would not last).
- **Common names** displayed as FM shows them (for example "Emerson Royal").
- **Staff and manager club** shown on FM24 instead of "Club: Unknown".
- Research tooling: `Tools/fm-research.py` and `scan_arrays --date`, described
  in the [development guide](../development.md#scripted-research-toolsfm-researchpy).

## Known limits on FM24

- Injury "light training" and "full training" dates use FM27's meaning; FM24
  itself shows only an expected return date between them.
- One witness (Heung-Min Son) reads his wage and one bonus about 1% above FM's
  display; the cause is unknown.
- Languages, name editing, staff contract wage/expiry and staff nationality are
  not mapped on FM24.

[FM24 memory layout](../fm24/memory-layout.md) for witnesses and details.
