# FM Editor 0.4.3 — preview notes

Unsigned experimental preview for Windows x64 and Linux x64 (Proton). Back up
saves and use offline single-player saves only. Epic installs remain unsupported
(see the [0.4.1 notes](0.4.1.md#compatibility-limits)).

## Changes since 0.4.2

- **FM27 PC Game Pass** (Xbox app, Store package 0.9.2435.0) now attaches with
  its own module addresses: player, staff and club arrays, the current game
  date, and the full-finance, player-coach and human-manager classes. Struct
  offsets are the Steam ones; every field checked matched.
- Two Spurs players matched FM on all visible attributes, dates of birth,
  caps, squad status and contract expiry, and one edit was confirmed in game
  and undone.
- The managed club is found from the human-manager class, skipping the Xbox
  account placeholder, as on Steam.

FM24, FM26 and FM27 Steam behaviour is unchanged.

## Known limits on Game Pass

- Only Store package 0.9.2435.0 is mapped. A Game Pass update changes
  `game_plugin.dll`; the editor then rejects the fingerprint until the new
  package is brought up.
- Club finances, stadium, club membership / My clubs and club policy stay
  disabled or unverified on Game Pass.

See the [changelog](../../CHANGELOG.md) and the
[FM27 Game Pass section](../fm27/memory-layout.md#game-pass-build) for
witnesses and details.
